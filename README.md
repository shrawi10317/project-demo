# Project Demo Website

A modern, responsive website showcasing web-based projects and demonstrating my web development capabilities.

## About

This website serves as a showcase for web applications I can design and develop for diploma and college students. It highlights project demonstrations, key features, technologies used, and available customization options.

## Featured Projects

### 1. Smart Internship Portal

A web-based platform that connects students and companies for internship discovery and recruitment management.

**Key Features**

* Student and company authentication
* Internship posting and browsing
* Search and filtering
* Resume uploads and applications
* Application status tracking
* Company dashboard

**Technologies:** Python, Flask, SQLite, HTML, CSS, JavaScript, Bootstrap

### 2. ShopSphere

A smart e-commerce web application that provides an online shopping experience with personalized product recommendations.

**Key Features**

* User authentication
* Product browsing and category filtering
* Shopping cart and wishlist
* Order management
* Personalized product recommendations
* Responsive user interface

**Technologies:** Python, Django, SQLite, HTML, CSS, JavaScript, Bootstrap

### 3. KrishiMitra AI

A multilingual, voice-based farmer advisory web application designed to make agricultural information more accessible.

**Key Features**

* Voice-based interaction
* AI-powered agricultural assistance
* Multilingual support
* Speech-to-text and text-to-speech
* Weather and location-based information

**Technologies:** Python, Flask, AI, Faster-Whisper, Groq, Edge TTS, SQLite, JavaScript, Generative AI

## Getting Started

### Prerequisites

* A modern web browser
* A code editor such as Visual Studio Code

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shrawi10317/project-demo.git
   ```

2. Open the project folder:

   ```bash
   cd project-demo
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
